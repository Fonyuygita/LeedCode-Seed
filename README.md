## 📘 About

The **IWS LeetCode Challenge** is an initiative designed to help interns and developers prepare for technical interviews at top tech companies. Each month, we curate a list of LeetCode problems covering various data structures and algorithms topics, organized by week and difficulty.

Our goal is to help you:
- Build a strong foundation in data structures and algorithms
- Develop systematic problem-solving skills
- Understand both brute force and optimized approaches
- Master time and space complexity analysis
- Learn common patterns used in technical interviews

## 🎯 How to Participate

1. **Fork this repository**
2. **Solve the weekly problems** at your own pace
3. **Commit your solutions** with the following format:
   ```
   /Year-Month/Week-X/Problem-Name/solution.[language]
   ```
4. **Include a detailed write-up** explaining:
   - Problem understanding
   - Brute force approach with complexity analysis
   - Optimized approach with complexity analysis
   - Lessons learned
5. **Create a pull request** to share your solutions

## 🧠 Problem-Solving Approach

For each problem, follow this structured approach:

1. **Understand the problem** - Read carefully, identify input/output, constraints
2. **Brute Force Approach** - Develop an initial solution, even if inefficient
3. **Optimized Approach** - Improve time/space complexity
4. **Complexity Analysis** - Analyze both approaches
5. **Implementation** - Code the solution in your preferred language
6. **Testing** - Verify with examples and edge cases
7. **Reflection** - Document what you learned
